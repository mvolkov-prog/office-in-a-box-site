Вопросы

Нужна ли подписка на ChatGPT или Claude?

Нет. Подключаешь то, что уже есть: Claude Code, Codex, ключ OpenAI-совместимого API или локальную модель через Ollama. Без ключей девочки просто живут и болтают заготовками.

Мои данные куда-то уходят?

Переписка, память и сессии хранятся у тебя на компьютере. Наружу уходит только то, что ты сам отправляешь выбранной LLM.

Можно доступ из России?

Да: работает с Yandex AI Studio, российскими агрегаторами (OpenAI-совместимыми) и локальными моделями. Оплата нарисованных девочек — картой РФ.

Она правда может что-то сделать в моём проекте?

Да, если выберешь папку: она работает через Claude Code или Codex с их обычными разрешениями. Ничего не делает молча — видно каждый файл и команду, можно остановить.
